# Descomplicando a Docência

Portal web de serviços e produtos educacionais — site do GitHub Pages, em arquitetura estática, client-side, responsiva e acessível.

## Visão geral

Este projeto foi estruturado para funcionar 100% no cliente, com HTML, CSS e JavaScript puros, sem dependência de runtime do servidor. Ele foi pensado para publicar em GitHub Pages e seguir o modelo de hash routing para evitar 404 em navegação direta.

## Requisitos

- Node.js 20+
- Git
- GitHub Pages

## Instalação
